# RUCKUS One API Inspector

A browser extension for observing and visualizing API requests made by the RUCKUS One web interface. It helps network engineers understand the sequence and relationships of calls generated by UI workflows.

## Current version: 2.11.0

### Core features

- **Live Capture** — observe API requests while navigating RUCKUS One.
- **Workflow Discovery** — group captured calls into likely UI workflows using timing and endpoint patterns.
- **Visual API Flow** — visualize the chronological order of observed calls.
- **API Relationships** — inspect endpoint and field relationships inferred from captured traffic.
- **Troubleshooting** — review errors, response times, and endpoint patterns.

The separate **Workflow Trace** recorder and manual action-marker workflow have been removed in v2.11.0. Workflow Discovery and Visual API Flow use the live captured request stream directly.

## Install in Chrome or Edge

1. Download and extract the Chrome/Edge package.
2. Open `chrome://extensions` in Chrome or `edge://extensions` in Edge.
3. Enable **Developer mode**.
4. Select **Load unpacked** and choose the extracted extension folder containing `manifest.json`.
5. Open RUCKUS One, start Live Capture, navigate through a workflow, then inspect Workflow Discovery and Visual API Flow.

## Install in Firefox

1. Download and extract the Firefox package.
2. Open `about:debugging#/runtime/this-firefox`.
3. Select **Load Temporary Add-on** and choose the extension's `manifest.json`.
4. Open RUCKUS One and test Live Capture, Workflow Discovery, and Visual API Flow.

Temporary Firefox add-ons normally need to be loaded again after Firefox restarts.

## Security and privacy

Captured traffic may include tenant identifiers, personal information, internal URLs, or authentication-related material. Treat captures as sensitive operational data. Review and sanitize captures before sharing them. Never commit credentials, tokens, browser profiles, or real tenant traffic.

Use the extension only with systems and accounts you are authorized to access, and follow your organization's security policies and applicable service terms.
